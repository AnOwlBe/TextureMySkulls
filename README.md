# TextureMySkulls
TextureMySkulls is a simple plugin that allows you to easily use the textured sprite heads introduced in Minecraft 1.21.9.

## Supported Listeners
> System Chat  
> Action Bar  
> Boss Bar  
> Team DisplayName/Prefix/Suffix  
> Title/Subtitle  
> Inventory Name/Item Name/Item Lore  
> Scoreboard Title/Lines (if they use team prefix)  
> Disconnect Message  
> Resource Pack Prompt  
> If there's a listener that's missing and you want it added, make an issue on the GitHub!

## Guide
First, you'll need a base64 texture.

To do this, head to https://minecraft-heads.com/custom-heads, pick a head, then scroll down until you see `Developer Information`.

After you've done that, click 'copy' on the 'value'.

And that's it! You can now use that value in-game alongside `<skull_texture:...>`.
